# 桌面精灵测试指南

## 🧪 测试前准备

### 1. 确保依赖已安装

```powershell
cd clients\desktop
npm install
```

### 2. 确保后端服务已启动

```powershell
# 在项目根目录
.\start.bat
```

### 3. 启动桌面精灵

```powershell
cd clients\desktop
.\run_with_dapr.ps1
```

---

## ✅ 测试清单

### 1. 消息持久化测试

#### 测试步骤：
1. ✅ 启动桌面精灵
2. ✅ 发送 3-5 条消息
3. ✅ 等待 AI 回复
4. ✅ 关闭应用（完全退出）
5. ✅ 重新启动应用
6. ✅ 验证消息是否保留

#### 预期结果：
- ✅ 消息历史完整保留
- ✅ 消息顺序正确
- ✅ 时间戳显示正确

#### 测试清空功能：
1. ✅ 发送几条消息
2. ✅ 点击标题栏的清空按钮（🗑️）
3. ✅ 确认对话框
4. ✅ 验证消息是否清空
5. ✅ 重新打开应用验证消息是否清空

---

### 2. 打字机效果测试

#### 测试步骤：
1. ✅ 发送一条消息（例如："请介绍一下你自己"）
2. ✅ 观察 AI 回复是否逐字显示
3. ✅ 验证打字过程中光标是否闪烁
4. ✅ 验证打字完成后消息是否完整保存

#### 预期结果：
- ✅ AI 回复逐字显示（打字机效果）
- ✅ 打字过程中显示闪烁光标
- ✅ 打字速度适中（约 20ms/字符）
- ✅ 打字完成后消息完整保存

#### 测试长文本：
1. ✅ 发送："请写一首关于春天的诗"
2. ✅ 观察长文本的打字机效果
3. ✅ 验证是否流畅无卡顿

---

### 3. UI 改进测试

#### 测试步骤：
1. ✅ 检查标题栏是否显示清空按钮（仅在消息存在时）
2. ✅ 检查每条消息是否显示时间戳
3. ✅ 检查加载状态是否区分"思考中"和"正在输入"
4. ✅ 检查打字过程中输入框是否禁用

#### 预期结果：
- ✅ 清空按钮位置正确，仅在消息存在时显示
- ✅ 时间戳格式正确（例如：14:30:25）
- ✅ 加载状态提示清晰
- ✅ 打字过程中输入框和发送按钮禁用

---

### 4. 语音功能测试

**前置**：语音采集（麦克风、VAD）需使用 **`ambient` 特性** 启动或构建：
- 开发：`npm run tauri:dev:ambient`
- 构建：`npm run tauri:build:ambient`

#### 测试步骤：
1. ✅ 点击麦克风按钮
2. ✅ 说话（例如："你好"）
3. ✅ 点击停止按钮
4. ✅ 观察语音识别和回复
5. ✅ 验证回复是否使用打字机效果

#### 预期结果：
- ✅ 语音识别正确
- ✅ AI 回复使用打字机效果
- ✅ 语音回复播放正常（如果启用）

---

### 5. 存储限制测试

#### 测试步骤：
1. ✅ 发送超过 100 条消息（可以快速发送相同消息）
2. ✅ 验证是否只保留最近 100 条
3. ✅ 重新打开应用验证消息数量

#### 预期结果：
- ✅ 只保留最近 100 条消息
- ✅ 旧消息自动清理
- ✅ 存储空间不足时自动处理

---

### 6. 错误处理测试

#### 测试步骤：
1. ✅ 停止后端服务
2. ✅ 尝试发送消息
3. ✅ 验证错误消息是否显示
4. ✅ 验证错误消息是否保存

#### 预期结果：
- ✅ 错误消息正确显示
- ✅ 错误消息保存到历史
- ✅ 错误消息使用打字机效果（可选）

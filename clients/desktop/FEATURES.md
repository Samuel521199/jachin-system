## 使用说明

### 基本操作

1. **发送消息**：
   - 在输入框输入消息
   - 按 `Enter` 发送
   - 按 `Shift + Enter` 换行

2. **查看回复**：
   - AI 回复自动显示在左侧
   - 消息按时间顺序排列
   - 自动滚动到最新消息

3. **检查连接**：
   - 顶部状态栏显示连接状态
   - 绿色圆点 = 已连接
   - 红色圆点 = 未连接

### 快捷键

- `Enter` - 发送消息
- `Shift + Enter` - 换行
- `Ctrl + K` - 清空对话（待实现）
- `Ctrl + /` - 显示快捷键（待实现）

## 技术栈

- **前端**: React 18 + TypeScript + Tailwind CSS
- **后端**: Rust (Tauri v2)
- **状态管理**: Zustand
- **通信**: Dapr (HTTP)
- **构建工具**: Vite

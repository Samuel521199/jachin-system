官方 MCP 参考实现（Anthropic / modelcontextprotocol/servers）
============================================================

1) Python 包（pip）
   pip install -r tools/mcp-official/requirements-official-mcp.txt
   说明：requirements-official-mcp.txt 仅使用英文注释（ASCII），避免 Windows 下 pip 按 GBK 读文件时报 UnicodeDecodeError。

2) 与 Jachin L2 侧载
   将 tools/mcp-official/mcp_servers.jachin.example.json 中需要的条目合并到
   %USERPROFILE%\.jachin\mcp_servers.json（注意替换 REPLACE_* 路径）。
   Windows 建议为各 server 配置 env.PYTHONIOENCODING=utf-8。

3) Filesystem 核心能力在 npm 包（非 PyPI）
   npx -y @modelcontextprotocol/server-filesystem <允许访问的目录...>

4) 其它官方镜像（Docker）
   见各子目录 README：如 mcp/fetch、mcp/time（https://github.com/modelcontextprotocol/servers）

5) 调试
   npx @modelcontextprotocol/inspector uvx mcp-server-fetch
   或（pip 后）npx @modelcontextprotocol/inspector python -m mcp_server_fetch

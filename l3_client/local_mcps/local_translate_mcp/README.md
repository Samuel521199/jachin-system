# Local Translate MCP

This MCP loads OPUS-MT CTranslate2 INT8 model assets installed by L3:

```text
~/.jachin/models/com.jachin.model.opus-mt-en-zh-ct2-int8/model
~/.jachin/models/com.jachin.model.opus-mt-zh-en-ct2-int8/model
```

It is intentionally separate from the model packages. Updating this MCP should
not redownload or overwrite user-installed models.

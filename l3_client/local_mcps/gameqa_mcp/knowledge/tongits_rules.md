# Tongits 游戏规则（知识层 · 游戏内「GAME RULES」整理）

> 来源：游戏内帮助页 **How to play / Meld / Win & Lose**。  
> 本文供 **GameQA / Agent** 做胜负判定、术语对齐与 UI 文案核对；与线上版本若有出入，以游戏内最新文案为准。

---

## 1. 基本玩法（How to play）

- Tongits 为 **3 人**、使用 **标准 52 张牌** 的类 Rummy 纸牌游戏。
- **发牌**：每位玩家 **12 张**，**庄家 13 张**；其余牌为 **中央牌堆（central stack）**。
- **开局**：由 **庄家先打出（dump）一张牌** 后，游戏开始。
- **回合操作**：下家可以  
  - **捡起刚打出的弃牌**，当且仅当该牌能 **组成搭子** 或 **补全已有搭子**；或  
  - 从 **中央牌堆** 摸一张。  
  目标：组成搭子，并 **打出不需要的牌**。
- **终局条件**（满足其一即进入结算相关流程）：  
  - 有人以 **Tongits** 方式获胜；或  
  - 有人 **宣告和局（Draw）**；或  
  - **中央牌堆被摸完**。  
- **比点**：在需要比点的结算中，**手中剩余牌点数总和更低者** 获胜（详见「计点」）。

## 2. 搭子（Meld）

### 2.1 定义与策略

- **Meld（搭子）**：为赢得游戏需要收集的 **合法牌型组合**。
- 玩家凑成搭子后，可选择 **摊开在桌上** 或 **扣在手中（secret）**。
- **重要惩罚**：若 **终局时** 玩家 **从未在桌上摊开过任何一条搭子**，则视为 **被烧（Burned）**，且 **无法参与 Fight（见下）**。

### 2.2 搭子种类（Kind of melds）

| 类型 | 说明 |
|------|------|
| **Three-of-a-kind（三条）** | 三张 **点数相同** 的牌。 |
| **Four-of-a-kind（四条）** | 四张 **点数相同** 的牌。 |
| **Straight flush（同花顺）** | 至少 **三张**、**同花色** 且 **点数连续** 的牌。 |

## 3. 胜负与特殊机制（Win & Lose）

### 3.1 以 Tongits 获胜

若玩家能够 **用光全部手牌**，方式包括（满足其一即可）：

- 手牌全部进入 **自己的组合**；或  
- 通过 **贴牌（drop）到桌上已有搭子** 消掉手牌；或  
- 以规则允许的方式 **打完所有手牌**。  

则该玩家以 **Tongits** 获胜。

### 3.2 Fight（开战）

- **触发 Fight 的条件**：玩家在 **本回合** 将 **一组组合放到桌上**，且 **没有任何玩家** 在该回合把牌 **贴到该玩家的这条搭子上**。
- **Fight 后果**：  
  - 宣告 Fight 后，**没有任何明面搭子或暗扣搭子** 的玩家会被 **烧（Burned）**。  
  - 其余玩家可选择 **接受** 或 **拒绝挑战（Challenge）**。

### 3.3 中央牌堆摸完

- 当 **中央牌堆无牌可摸** 时，**本局结束**。
- **无任何明面或暗扣搭子** 的玩家会被 **自动判烧**（游戏内原文表述可能为 *burned automatically loses*，测试时需以实际 UI 字符串为准）。
- **总点数最低** 的玩家获胜。

### 3.4 Burned（被烧）

- 终局时 **无法形成任何搭子/组合** 的玩家记为 **Burned**。  
- 与「从未摊开过搭子」等规则叠加时，以游戏内实际结算顺序与提示为准。

## 4. 计点（Card points）

用于终局比点或结算展示（具体以游戏结算界面为准）：

| 牌 | 点数 |
|----|------|
| **A** | 1 分 |
| **J、Q、K** | 各 10 分 |
| **2–10** | 等于牌面数字 |

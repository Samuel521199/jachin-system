# English Tutor MCP

Offline L3-local MCP used to validate the L1 publish and L3 packaged install flow.

It supports five learning abilities without calling external models:

- sentence correction
- Chinese/English translation for common words and short phrases
- word explanation
- example sentence generation
- quiz generation and answer checking

The package exposes both:

- `tools[]` metadata in `plugin.json` for packaged L3 dynamic tool loading
- `stdio_server` metadata for standard MCP stdio execution

## 一、本周工作概述

本周围绕 **Tongits 主循环机器人** 完成从「绿圈 + 分战区 YOLO」到「全屏一次推理 + 坐标分桶 + 数据自动采集」的架构演进，并连续修复手牌漏检、截屏误抓、全屏被破坏、标记图未保存、回合结束误标记等生产环境问题。当前主路径已可稳定输出五战区战报，并具备影子特训（错题自动捕获）能力。

## 二、完成事项（逐条）

### 2.1 主循环与回合触发

1. **确立默认挂机模式**：绿圈轮询（约 0.2s 防抖）→「到我的回合」→ 延迟 1s → 全屏截屏 → YOLO 推理 → 打印战报；非 `--continuous` 每秒连续侦察。
2. **绿圈探针**：基于左下角头像 ROI 绿色边框像素计数，配合 `TURN_ENTER_FRAMES` / `TURN_EXIT_FRAMES` 防抖，区分「等待 / 我的回合」。
3. **异步侦察**：YOLO 推理在后台线程执行，主线程持续轮询绿圈，避免推理阻塞下一回合检测。
4. **发牌状态探针**：手牌区白牌/边缘像素比例未达标时跳过侦察，避免未发牌空等。
5. **Bootstrap 首帧同步**：脚本启动首帧仅同步回合状态、不触发「到我的回合」，降低启动瞬间误截屏概率。

### 2.2 YOLO 视觉感知架构

6. **接入 YOLOv8 全屏推理**：权重路径 `scripts/model/weights.pt`，默认 `conf=0.10`（10% 置信度，优先召回）。
7. **架构简化为「全屏一次推理 + 坐标分桶」**：模型负责检测全部牌面；宿主按五战区 ROI 将检测框中心点落入：我的手牌 / 我方明牌 / 左对手 / 右对手 / 中央弃牌顶牌。
8. **战报格式标准化**：按固定顺序输出各战区牌型与坐标，示例：
   - `我的手牌 N 张: [CA@(x,y), ...]`
   - `我方已亮明牌 / 左侧对手明牌 / 右侧对手明牌 / 中央弃牌顶牌`
9. **移除分战区裁切 + 条带推理主路径**（曾为提升手牌召回而加，后按「速度优先 / 全屏交给模型」策略收敛为单次全屏）。

### 2.3 手牌与 ROI 调优（历史迭代，部分已收敛）

10. **手牌 ROI 比例化**：默认宽 ROI（约屏宽 1%～99%，高度 56%～96.5%），支持 `TONGITS_HAND_ROI_*_RATIO` 环境变量。
11. **曾实现 4 等分 / 滑动窄窗条带推理**：解决整幅手牌压进 `imgsz=1280` 后单牌过小导致只检 3～4 张的问题；后在全屏架构下不再作为主路径。
12. **曾实现二次增强、边缘专扫、全屏补漏**：按用户要求以速度为第一优先级后移除或改为可选关闭。
13. **我方明牌区 `my_melds`**：独立 ROI（按钮上方槽位），纳入战报与分桶。

### 2.4 截屏链路稳定性

14. **多级截屏回退**：Windows 优先 `ImageGrab`（与用户所见前台一致）→ `mss` → `pyautogui`；纯被动读屏，不操作鼠标/键盘/窗口。
15. **移除窗口聚焦逻辑**：曾用 `ShowWindow(SW_RESTORE)` + `SetForegroundWindow` 试图解决首轮截到桌面问题，已确认会破坏浏览器 F11 全屏，已彻底删除。
16. **启动预热 8s（`TONGITS_STARTUP_GRACE_SEC`）**：脚本启动后一段时间内不截屏，给用户切回游戏窗口的时间。
17. **截屏被动预热（`TONGITS_CAPTURE_WARMUP`）**：模型加载前读一帧丢弃，缓解 mss 冷启动 `ReleaseDC` 失败。
18. **牌桌蓝区校验**：中央区域 HSV 蓝/青比例不足则判定非牌桌（过滤桌面/PowerShell 误帧）。
19. **截屏重试机制**：非牌桌或 YOLO 0 检出时最多重试 2 次，间隔 1.5s。
20. **修复 mss 弃用警告**：`mss.mss()` 改为优先 `mss.MSS()`。

### 2.5 标记图与调试输出

21. **新增 `scripts/yolo_marked/`**：每回合侦察成功且检出 ≥1 张牌时，保存 YOLO 标注图（默认仅牌框，不显示置信度数字）。
22. **标记图默认不叠加五战区大框**：`TONGITS_YOLO_MARKED_SHOW_ROI=1` 时可开启 ROI 调试框。
23. **修复标记图不保存 Bug**：原逻辑 `save_marked = attempt == retries` 导致首轮成功时不保存；已改为检出成功即保存。
24. **文件名规范**：`{时间戳}_raw{N}_n{M}_marked.jpg`（N=模型检出数，M=分桶后数）。
25. **0 检出 / 非牌桌诊断日志**：明确提示「截屏可能不是游戏画面，请保持全屏且在最前」。

### 2.6 影子特训（错题自动捕获）

26. **新增 `scripts/hard_examples/` 目录**：启动时自动创建。
27. **心虚检测机制**：扑克牌类别名长度 ≤ 3，且置信度 ∈ [0.50, 0.80] 时触发「犹豫期」抓拍。
28. **保存内容为截屏原图**（非 YOLO plot 标注图），供 V6 重新标注训练。
29. **命名规范**：`hard_example_YYYYMMDD_HHMMSS.jpg`。
30. **战术冷却 3.0s**：成功保存一次后 3 秒内不再重复入库，防止静止画面刷盘。
31. **醒目战报**：终端红色高亮输出 `🚨 [警报] 发现高价值心虚错题！已自动抓拍入库！`。
32. **环境变量**：`TONGITS_HARD_EXAMPLES`、`TONGITS_HARD_EXAMPLE_COOLDOWN_SEC`、`TONGITS_HARD_EXAMPLE_HESITANT_LO/HI`。

### 2.7 回合结束保护（WIN 徽标）

33. **头像 WIN 结算徽标检测**：左下角头像区黄色 WIN 字 + 红色飘带像素比例超阈值 → 判定回合已结束。
34. **回合结束时不标记**：跳过 YOLO 推理、`yolo_marked` 保存、`hard_examples` 影子特训。
35. **延迟后绿圈消失检测**：等待 1s 后若绿圈已消失，直接跳过本轮侦察。
36. **可调阈值**：`TONGITS_WIN_YELLOW_RATIO_MIN`、`TONGITS_WIN_RED_RATIO_MIN`。

### 2.8 运行环境与入口

37. **`scripts/run_main_bot_loop.bat`**：优先使用 `.venv-omniparser` 规避 Anaconda base 的 `c10.dll` 加载失败。
38. **CLI 模式**：`--save-only` 仅截图、`--continuous` 调试连续侦察、`--yolo-once` 单次侦察、`--debug` 绿圈/ROI 校准窗口。
39. **环境变量文档化**：在 `main_bot_loop.py` 文件头集中列出常用 `TONGITS_*` 配置项。

## 四、当前系统架构（简图）

```
[绿圈轮询 ~0.2s]
       ↓ 上升沿「到我的回合」
[启动预热已过?] → 否 → 跳过
       ↓ 是
[延迟 1s] → [绿圈仍在?] → 否 → 跳过
       ↓ 是
[ImageGrab/mss 截屏] → [牌桌校验] → [WIN 徽标?] → 是 → 跳过
       ↓ 否
[YOLO 全屏推理 conf=0.10]
       ↓
[心虚检测?] → 是 → [hard_examples 原图 + 3s 冷却]
       ↓
[五战区坐标分桶] → [战报日志]
       ↓
[检出≥1] → [yolo_marked 标注图（无置信度数字）]
```

## 七、已知限制与后续建议

1. **截屏范围为整屏**：含浏览器地址栏/任务栏时，与「纯牌桌 canvas」存在差异；建议游戏 **F11 全屏** 且脚本启动后 8s 内切回游戏。
2. **全屏单次推理**：小目标（远端对手明牌）召回依赖模型本身；可继续收集 `hard_examples` 训练 V6。
3. **WIN 检测为颜色启发式**：不同皮肤/特效下可能需要微调 `TONGITS_WIN_*_RATIO`。
4. **决策与自动操作未接线**：当前以「侦察 + 数据采集」为主，Drop/Fight/Group/Dump 自动点击尚未接入主循环。
5. **建议下周**：V6 训练流水线、窗口/client 区域裁切（仅 game canvas）、与规则引擎对接实现自动出牌。

## 1. 两个网址，先收藏

### 1.1 地址一览

| 做什么 | 打开 |
|--------|------|
| 注册账号、逛商店、**下载桌面端** | **http://47.86.39.173:3000/** |
| **管理员**：审批你的电脑接入团队 | **http://47.86.39.173:18888/gateway/** |

### 1.2 谁该用哪个

普通用户日常主要用 **第一个**；需要管理员帮你「通过接入」时，把 **第二个** 发给管理员即可。

## 2. 最少几步能用起来

### 2.1 四步上手

1. 浏览器打开 L1 地址 → **注册 / 登录**。
2. 在站内找到 **桌面端下载**，安装 **Jachin 桌面端**（Windows）。
3. 打开桌面端，在设置里填 **L2 网关**：`http://47.86.39.173:18888` → 发起 **神经接驳**；请 **管理员** 在第二个网址里 **同意你的设备接入**。
4. 按 **`Alt` + `Shift` + `空格`**，或点任务栏右下角的 **Jachin 托盘图标**，打开 **Omni**，直接打字下指令。

### 2.2 退出与托盘

> 关主窗口 ≠ 退出：程序还在托盘里。要彻底退出：**托盘右键 →「退出 Jachin」**。

把下面的话改一改就能用；具体能否执行取决于团队是否已 **订阅** 对应技能/插件。

## 4. 想给助手「加能力」时

### 4.1 在 Store 里订什么

在 L1 打开 **Store（商店）**，可按需 **订阅**：

- **Skills**：像给助手换一套「专业流程 / 人设」。
- **MCPs**：连接飞书、Notion、数据库等外部系统；有的要配 API Key。
- **Tools（基础能力）**：多数已 **内置**，一般不用单独订阅。

### 4.2 同步到电脑

订阅后会 **自动同步** 到你已接驳的电脑，通常不用自己下安装包。

## 5. 卡住时先看这几条

### 5.1 现象与处理

| 现象 | 可尝试 |
|------|--------|
| 网页打不开 | 检查网络 / 公司代理；问运维服务是否正常 |
| 一直「待审批」 | 让管理员登录网关，在 **节点审批** 里通过 |
| 快捷键没反应 | 用 **托盘左键** 打开 Omni；关掉 PowerToys 等与 **Alt+空格** 冲突的软件 |
| 提示无权调用工具 | 联系管理员确认是否已 **订阅** 技能/MCP、电脑是否已 **接驳** |

## 6. 高级用法（工作区管理员 / 运维向）

本节给 **负责人 / 管理员**（以及需要代同事操作网关的人）：在「会用 Omni」之外，还要管 **网关、节点与密钥**。普通成员 **不必** 做这些事。

### 6.1 谁能进管理网关？

- 在 L1 工作区里角色为 **owner（负责人）** 或 **admin（管理员）** 的账号，才通常能完成 **L2 网关** 登录与后续操作。
- 仅用 **成员** 身份时，访问网关可能 **403**，属正常现象。

### 6.2 先让网关「认识」神经集市（L1 ↔ L2）

**目的**：云端 **商店清单、订阅的 Skill/MCP** 才能同步到网关，供已接驳的电脑拉取。

1. 打开 **http://47.86.39.173:18888/gateway/**
2. **用户名**填 L1 注册 **邮箱**，**密码**填 **同一套 L1 密码**（网关不向 L2 存明文密码，由服务端向 L1 校验）。
3. 若 L1 只支持第三方登录、没设密码：用页面上的 **「使用 Nexus 账号登录」** 跳 L1 授权后再回来。
4. 部分环境有运维账号 **`admin` / `admin123`**（若未改密），仅作兜底；生产环境请按团队规范改密并绑定 L1。

> 已配对过的环境，若仍显示 **「快速登录」** 且 L1 可达，可用它减少重复输密码（以页面为准）。

### 6.3 审批同事电脑接入（L2 ↔ L3 · 神经接驳）

同事在桌面端填好网关 `http://47.86.39.173:18888` 并提交后，设备会出现在网关的 **待审批 / 节点** 列表里。

1. 登录网关 → 找到 **节点审批**（或同类菜单）。
2. 选中对应设备 → 选择要绑定的 **子账号** → **同意接入**。
3. 同事侧等待状态变为已接入；若长时间不行，核对 **L2 地址是否填对**、网络是否通。

> 审批 **只在 L2 做**，不是在 L1 网站里「配对电脑」。

### 6.4 子账号与 API Key（常见管理动作）

网关中通常还可为子账号 **添加 / 管理 API Key**（如对话模型用的 Key 等，以实际菜单为准）。密钥由控制面 **加密下发** 到已批准节点，勿在聊天里明文转发。

### 6.5 与同事分工时怎么说

| 场景 | 你可以这样安排 |
|------|------------------|
| 新人要装客户端 | 发 **L1 下载地址**；告知装好后在桌面端发起 **神经接驳** |
| 新人卡在「待审批」 | 你登录网关 → **节点审批** → 选子账号 → **同意** |
| 团队要统一某 MCP | 在 L1 **Store** 订阅后，确认网关已与 L1 同步，再让各节点 **已接驳** |

更细的权限说明、多工作区、命令行配对等见 **[USER_GUIDE_NEXUS_PUBLIC.md](./USER_GUIDE_NEXUS_PUBLIC.md)** 第 9 章及前后章节。

# K11 平台冒烟测试用例

> 来源：`K11平台测试用例.xlsx`（本地维护时可同步更新本页）  
> 用途：发布前冒烟检查  
> 站点示例：<https://www.kalaroko.com/>

## 使用说明

- 按 **推荐执行顺序** 列安排手工或自动化步骤。
- **物理层 MCP**（截屏 + 坐标点击）适合 Canvas / 无稳定 DOM 的流程；Console、标题、DOM 断言需浏览器自动化（如 Puppeteer）。
- 表中 **结果** 列在原表为占位（如 `0`），执行时改为 Pass/Fail 或打勾即可。

## 优先级说明

| 级别 | 含义 |
|------|------|
| **P0** | 必须通过；不通过不能发 |
| **P1** | 重要功能；建议发布前通过 |
| **P2** | 次要检查项；可作为补充确认 |

## 使用说明

- **桌面安装包 / 另一台电脑**：统合冒烟由 L3 HTTP 子进程执行 Playwright 脚本。请使用**完整安装目录**（含 `bin/l3_node-*.exe`、`scripts/`、`.env`），勿只拷贝单个 `l3_node.exe` 到任意文件夹；并需**重新构建侧车**（`python scripts/build_l3_sidecar.py` 或 `npm run tauri:build`）以带上内嵌的 `test_k11_*.py`。环境变量 `JACHIN_APP_ROOT` 由主程序拉起侧车时注入，用于脚本定位仓库根与 `.env`。
- **控制台报「L3 技能 API 不可达」**：与东南亚/中国节点切换**无直接关系**；若 `JACHIN_ACTIVE_REGION` 与 `DASHSCOPE_API_KEY` / `DASHSCOPE_API_KEY_SEA` 不一致，旧版 `--ws-only` 可能在**引擎初始化失败时整进程退出**，导致 HTTP 未监听。请检查安装目录或 `%LOCALAPPDATA%\Jachin Desktop Sprite\` 下 `.env`、`l3_debug.log`；确保 `bin\l3_node-x86_64-pc-windows-msvc.exe` 存在（日志里曾出现 `os error 2` 即侧车路径缺失）。更新侧车/主程序后引擎失败时仍会先起 HTTP，便于探测与 K11。
- **L3 + browser-use · P1 五模块（客服 / Share / Task / Profile / Party 状态）**：业务逻辑可在 `skills_repo/k11-herontest-browser-qa/SKILL_P1_MODULES.md`（若存在）中维护；Chrome 已 `--remote-debugging-port=9222` 摆好页后执行：  
  `python scripts/run_k11_p1_modules_l3.py`（可选 `--cases p1_customer_service,...`）。
- **L3 + browser-use（P0 MCP 直连等）**：见 `scripts/test_browser_use_mcp.py` 及同目录 `skills_repo/k11-herontest-browser-qa/SKILL.md`。
- 按 **推荐执行顺序** 列安排手工或自动化步骤。
- **物理层 MCP**（截屏 + 坐标点击）适合 Canvas / 无稳定 DOM 的流程；Console、标题、DOM 断言需浏览器自动化（如 Puppeteer）。
- 表中 **结果** 列在原表为占位（如 `0`），执行时改为 Pass/Fail 或打勾即可。

## 优先级说明

| 级别 | 含义 |
|------|------|
| **P0** | 必须通过；不通过不能发 |
| **P1** | 重要功能；建议发布前通过 |
| **P2** | 次要检查项；可作为补充确认 |

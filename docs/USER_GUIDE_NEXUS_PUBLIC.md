# Jachin Nexus 用户使用说明书

本文面向**终端用户**，说明如何登录、下载、安装、配对与日常使用。若您部署的公网地址与下文不同，请以运维提供的地址为准。

---

## 1. 本产品是什么

**Jachin Nexus** 是一套分层架构的智能体平台：

- **Layer 1（L1）— 神经集市 / 账号与商店**：注册账号、浏览与订阅技能（Skill）、插件（MCP）、下载桌面客户端等。
- **Layer 2（L2）— 网关 / 控制面**：为「边缘节点」做审批与权限管理（例如将您的电脑/设备接入工作区、分配子账号与 API Key）。**L3 设备只与 L2 做「神经接驳」配对，不与 L1 直接配对。**

您日常接触最多的通常是：**浏览器打开 L1**，以及 **桌面端客户端**。

## 3. 准备工作

- **浏览器**：建议使用最新版 Chrome / Edge。
- **网络**：能访问上述 L1、L2 地址；若公司网络限制外网，请向网管放行。
- **账号**：在 L1 注册邮箱账号（用于登录神经集市、下载客户端；管理员亦可用同一邮箱登录 L2 网关）。
- **管理员角色**：在 L1 工作区内需为 **owner** 或 **admin**，才能在 L2 网关完成与 L1 的联邦登录及节点审批（见第 6、7 节）。

## 4. 登录 L1（神经集市）

1. 浏览器打开：**http://47.86.39.173:3000/**
2. 使用已注册邮箱完成注册或登录。
3. 登录后可使用：**应用商店 / 神经集市**、订阅技能与插件、**桌面端下载**、控制台等与产品相关的功能（具体菜单以页面为准）。

若首次使用需**创建工作区/组织**，请按页面引导完成（工作区与后续 L2 管理、L3 填写的组织信息相关）。

---

## 5. 下载桌面客户端

1. 登录 L1 后，在站点内找到 **桌面端下载**（或「Download」同类入口）。  
2. 根据您的系统选择 **Windows** 安装包（常见为 `.exe` / `.msi`）。  
3. 若下载页提示需登录或权限，请先完成 L1 登录。

> 说明：具体下载路径以你们部署为准（部分环境为独立下载站或与 Nexus 同域下的 `/desktop-downloads` 等）。若页面无法下载，请联系运维确认对象存储与发行版本是否已配置。

---

## 6. 安装桌面客户端（以 Windows 为例）

1. 双击下载的安装包，按向导完成安装。
2. 若出现 **Windows 安全 / SmartScreen** 提示：本软件若为团队刚发布的版本，可能尚未积累大量用户信任记录。若您确认来源为官方安装包，可选择「仍要运行」或「更多信息 → 仍要运行」（具体文案因系统版本而异）。
3. 安装完成后，从开始菜单或桌面快捷方式启动 **Jachin Desktop**（名称以实际安装为准）。

## 7. 配对说明（请您先分清两层）

### 7.1 L1 ↔ L2（网关与云端对齐）— **管理员在浏览器操作**

目的：让 **L2 网关** 信任您的 **L1 账号/租户**，以便同步商店清单、技能订阅等。

1. 浏览器打开：**http://47.86.39.173:18888/gateway/**
2. 推荐方式：在登录表单中  
   - **用户名**填写您在 L1 注册的 **邮箱**  
   - **密码**填写 **L1 同一密码**  
   由服务端向 L1 校验（L2 不保存您的 L1 密码）。
3. 若 L1 仅支持 OAuth、未设置密码：可使用页面上的 **「使用 Nexus 账号登录（推荐）」** 跳转到 L1 完成授权后返回（需部署侧配置正确）。
4. 运维兜底账号（若未修改）：部分环境提供本地 **`admin` / `admin123`**，仅用于维护；生产环境请尽快修改密码并按团队规范绑定 L1。
5. 已配对成功过的环境，可使用 **「快速登录」**（需 L1 可达且账号在 L1 侧具备网关权限）。

**权限提示**：与 L1 联邦登录相关的操作，通常仅 **工作区 owner / admin** 可用；普通成员可能无法完成网关登录。

### 7.2 L2 ↔ L3（神经接驳）— **桌面端 + 网关审批**

目的：让您的 **电脑/边缘节点（L3）** 接入团队，接收加密的 API Key、同步技能等。

1. 在 **桌面端** 找到连接/设置中的 **神经接驳**（或「连接 L2 网关」类入口）。
2. 填写 **L2 网关地址**：**http://47.86.39.173:18888**（通常不带 `/gateway/` 路径，以客户端提示为准）。
3. 发起接驳后，节点会进入 **待审批** 状态。
4. **工作区管理员** 登录 L2：**http://47.86.39.173:18888/gateway/** ，在 **节点审批** 区域找到您的设备，选择 **子账号** 并 **同意接入**。
5. 桌面端侧等待 **审批通过** 与密钥下发完成（具体以客户端状态提示为准）。

**重要**：**不存在「L1 与 L3 配对」**。审批 L3 只在 **L2 网关** 完成。

### 7.3 无图形界面环境（可选）

若服务器仅 SSH、无法打开浏览器，团队可使用 **命令行配对码** 等方式辅助 L1↔L2（由运维执行 `python -m core.cli pair` 等，用户在 L1 控制台输入配对码）。普通用户可忽略，除非文档另行通知。

## 8. 安装后如何使用（日常使用）

1. 启动桌面客户端，确认 **已与 L2 接驳成功**（或按团队说明使用「仅本地 Key」类离线模式——以产品实际选项为准）。
2. 在对话区输入任务，智能体会按已订阅的 **技能（Skill）** 与 **工具（含 MCP）** 执行。
3. 在 L1 **神经集市** 订阅新技能或插件后，一般由 L2 同步到边缘节点；若长时间不可用，请检查网络、L2 与管理员分配的权限。

---

## 9. 如何关闭程序（与「仅隐藏窗口」的区别）

适用于 **Jachin 桌面端（Windows）**。

1. **点控制台（主窗口）右上角关闭**  
   默认 **不会结束整个程序**，而是 **隐藏控制台窗口**。进程仍在运行，**系统托盘**（任务栏右下角通知区域）中会保留 Jachin 图标，便于稍后唤回（见下一节）。

2. **完全退出（推荐在需要关机、卸载或确认不再使用时操作）**  
   在托盘图标上 **单击鼠标右键**，选择 **「退出 Jachin」**。退出时会释放本机相关后台资源。

3. **再次启动**  
   从开始菜单或桌面快捷方式再次打开时，若程序已在后台运行，通常会 **自动聚焦已有窗口**（单实例），而不会重复开很多个副本。

## 10. 快捷键与托盘（唤出 Omni / 控制台）

以下为当前桌面端常见交互；若与您安装的版本不一致，以软件内说明或更新日志为准。

### 10.1 系统托盘

| 操作 | 作用 |
|------|------|
| **左键单击** 托盘图标 | 打开或切换 **Omni**（对话条 / 聊天界面） |
| **右键单击** 托盘图标 | 菜单：**「打开控制台」**（显示并聚焦主窗口）、**「退出 Jachin」** |

鼠标悬停在托盘图标上时，提示中通常会包含：**左键打开 Omni**、**右键可打开控制台或退出**，以及下文的全局快捷键说明。

### 10.2 全局快捷键（在多数界面可用，用于 Omni）

程序会按顺序尝试注册下面组合键，**以首次注册成功的一个为准**（常见为第一条）：

1. **Alt + Shift + 空格** — 切换 Omni（与左键托盘类似，便于键盘唤出）  
2. 若被系统或其它软件占用导致注册失败，可能回退为 **Ctrl + Shift + 空格**  
3. 再失败可能尝试 **Alt + 空格**  

说明：在 Windows 上 **Alt + 空格** 可能被 **PowerToys「运行」** 等软件占用。若全局快捷键无效，可检查 PowerToys 或其它热键工具中的冲突项，或改用托盘左键打开 Omni。

### 10.3 控制台窗口处于前台时（焦点在主界面内）

| 快捷键 | 作用 |
|--------|------|
| **Ctrl + Shift + E** | **鹰眼监控**：在「显示并聚焦控制台」与「隐藏控制台」之间切换；隐藏后仍可用托盘 **「打开控制台」** 找回主窗口 |
| **Ctrl + Shift + C** | **打开聊天窗口**（Omni） |

若快捷键无反应，请先确认键盘焦点是否在客户端窗口内；全局快捷键是否与其它软件冲突；以及程序是否仍在托盘后台运行（未执行「退出 Jachin」）。

## 12. 常见问题（FAQ）

**Q：我应收藏哪个网址？**  
A：日常使用 **L1** 逛商店与下载；需要审批设备或管理子账号时打开 **L2 /gateway/**。

**Q：登录 L2 提示 403？**  
A：您可能不是工作区 **owner/admin**，或 L1 账号未完成绑定。请联系工作区管理员。

**Q：桌面端一直「待审批」？**  
A：请管理员登录 L2 网关，在节点列表中完成分配；并确认 L2 地址填写正确、网络可达。

**Q：能否不经过 L2 使用？**  
A：部分客户端提供 **本地 API Key** 模式（跳过 L2），但将无法使用依赖 L2 同步的订阅能力；以客户端实际选项为准。

**Q：点了控制台关闭，为什么任务栏里还有 / 好像没关掉？**  
A：这是正常现象：关闭主窗口时多为 **隐藏窗口**，程序仍在 **托盘** 运行。需要彻底结束请用托盘右键 **「退出 Jachin」**（见第 9、10 节）。

**Q：数据隐私？**  
A：请同时阅读产品隐私政策与团队内部合规要求；API Key 在链路上多为加密下发，具体以官方安全说明为准。

## 13. 安全建议

- 勿向他人泄露 L1 密码、L2 管理权限与 API Key。
- 仅从 **官方提供的 L1 地址** 下载安装包。
- 在公共电脑使用后应 **退出登录**，并视情况在 L2 撤销节点或轮换 Key（若产品提供相应能力）。

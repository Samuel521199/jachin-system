## 1. 使用环境与前置要求（Prerequisites）

在开始前，请确认您的环境满足下列条件，可减少「装不上、连不上」的困扰。

### 1.1 操作系统与硬件

| 项目 | 说明 |
|------|------|
| **桌面客户端** | 当前公开发布的安装包以 **Windows 10 / Windows 11（64 位）** 为主。若您使用 **macOS / Linux**，请以团队实际提供的版本与说明为准。 |
| **磁盘空间** | 预留一定空间用于安装与后续更新（建议至少 **500 MB** 以上余量，具体随版本变化）。 |
| **权限** | Windows 安装时可能需要 **管理员同意**；若公司电脑受管控，请联系 IT 协助安装。 |

### 1.2 浏览器与账号

| 项目 | 说明 |
|------|------|
| **浏览器** | 访问网页控制台时，推荐使用最新 **Chrome** 或 **Edge**。 |
| **邮箱** | 需准备一个可收邮件的 **邮箱**，用于在「神经集市」注册与登录。 |

### 1.3 网络环境

| 项目 | 说明 |
|------|------|
| **访问公网** | 需要能打开管理员提供的 **L1（神经集市）** 与 **L2（管理网关）** 地址。家庭宽带一般无特殊设置。 |
| **公司内网 / 代理** | 若浏览器提示无法连接、下载失败，可能是公司防火墙或代理限制，请向 **网管** 申请放行相关域名或 IP，或按公司规范配置系统代理。 |
| **无需用户自行开启特殊端口** | 一般用户只需能正常浏览网页即可；除非团队另有书面说明，**不要求**您在本机手工开端口映射。 |

> **提示 (Tip)**：首次使用建议在 **网络稳定** 的环境下完成注册、下载与配对，避免中途失败需要重复操作。

## 2. 快速开始（Quick Start）

若您不想先读架构说明，可按下面 **5 步** 顺序操作（管理员与普通成员分工见各步说明）。

1. **打开神经集市并注册 / 登录**  
   在浏览器访问 **[http://47.86.39.173:3000/](http://47.86.39.173:3000/)**，用邮箱完成注册与登录；按页面提示创建或加入 **工作区**（若需要）。  
   > 📸 **[截图占位：L1 登录或首页，标出「注册 / 登录」入口]**

2. **下载并安装桌面客户端**  
   在已登录状态下找到 **桌面端下载**，下载 **Windows** 安装包并双击安装。  
   > 📸 **[截图占位：L1 桌面端下载页面或下载按钮位置]**

3. **（管理员）让管理网关认识您的团队账号**  
   **工作区管理员** 在浏览器打开 **[http://47.86.39.173:18888/gateway/](http://47.86.39.173:18888/gateway/)**，使用 **与 L1 相同的邮箱 + 密码** 登录（或使用页面上的「Nexus 账号登录」跳转授权）。这样云端商店与权限才能同步到网关。  
   > 📸 **[截图占位：L2 网关登录页，标出邮箱/密码与「快速登录」等入口]**

4. **（用户 + 管理员）把电脑「接入团队」——神经接驳**  
   打开已安装的 **Jachin 桌面端**，在设置里找到 **神经接驳 / 连接 L2**，填入网关地址 **`http://47.86.39.173:18888`**（是否带路径以客户端提示为准），发起申请。管理员在 **L2 网关 → 节点审批** 里为您的设备选择子账号并 **同意接入**。  
   > 📸 **[截图占位：桌面端「神经接驳」或网关地址填写界面]**  
   > 📸 **[截图占位：L2 网关「待审批节点」列表与「同意接入」按钮]**

5. **首次唤出 Omni 对话**  
   接驳成功后，按 **`Alt` + `Shift` + `空格`**（若无效见第 **12** 章「快捷键与托盘」），或 **鼠标左键单击任务栏右下角的 Jachin 托盘图标**，打开 **Omni** 聊天条，输入第一句话即可开始。  
   > 📸 **[截图占位：Omni 聊天条或对话界面，标出输入框]**

完成以上步骤后，可继续阅读 **第 3 章（认识核心概念）**、**第 4 章（探索 Store）**，再按文档顺序完成下载、安装、配对、快捷键等说明；**第 15 章（常见使用场景与示例）** 放在基础配置之后、故障排除段落之中，便于先会操作、再看示例。

## 3. 认识核心概念

本章帮助您快速建立对 Jachin Nexus 的「心智地图」。读完可先浏览 **第 4 章「探索神经集市 (Store)」** 了解如何给 Omni **订阅** 能力；完成地址、下载、配对、快捷键等基础操作后，可在 **第 15 章** 查看 Omni 的口语化用法。

### 3.1 名词白话对照（降低术语门槛）

产品里会出现一些「酷但略硬」的说法，下面用一句话帮您对齐日常理解（技术架构未改，仅方便记忆）。

| 术语 | 白话理解 |
|------|----------|
| **L1 / 神经集市** | **网站里的账号与商店**：注册、登录、下软件、逛技能与插件。 |
| **L2 / 管理网关** | **管理员用的网页后台**：审批谁的电脑能接入、管子账号和密钥等。**普通聊天一般不用天天打开它。** |
| **L3 / 边缘节点** | **您电脑上实际干活的那一侧**（常随桌面端一起运行）。可粗略理解成「您这台设备上的 Jachin 大脑」。 |
| **神经接驳** | **把您的电脑登记到团队里**，类似「设备绑定 / 接入审批」：要管理员在 L2 点同意，您的电脑才能拿到云端下发的权限与配置。 |
| **Skill（技能）** | **给智能体读的任务说明书**：告诉它这类事该怎么做。 |
| **MCP** | 可理解为智能体使用的 **外部能力插件**（例如连某个工具或服务），在商店里常与技能一起出现；**不必记英文全称。** |
| **Omni** | 桌面上的 **对话条 / 聊天窗口**：您在这里打字下指令、看回复。 |
| **控制台 / 鹰眼** | 偏 **仪表盘 / 设置向** 的主窗口（名称以版本为准），与 Omni 聊天可配合使用。 |

> **注意 (Note)**：**您的电脑只和「管理网关 L2」做接驳登记**，**不是**和 L1 网站直接「配对」。审批入口在 L2 网页。

### 3.2 本产品与分层分工（架构一图胜千言）

**Jachin Nexus** 把能力拆成几层，您只需记住分工：

- **L1**：浏览器里的 **账号 + 商店 + 下载**。  
- **L2**：管理员用的 **审批与密钥管理**（网页）。  
- **L3**：装在您电脑上的 **运行与对话**（桌面端）。

日常您用得最多的是：**浏览器打开 L1**，以及 **桌面上的 Jachin**。

## 4. 探索神经集市 (Store)：给助手扩充能力

在 **L1 神经集市** 里，进入 **Store（商店）** 页面，就像在手机里打开 **应用商店**：可以为 **Omni 助手** 选配、订阅各类能力，让同一套桌面端在不同场景下更顺手。

> 📸 **[截图占位：此处展示 Store 界面的三个选项卡：Skills, MCPs, Tools]**

下面三个模块在 Store 里通常以 **选项卡** 区分，名字可能是英文 **Skills / MCPs / Tools**，含义可以这么记：

### 4.1 🛠️ Tools（基础工具）

这是 **系统里已经预装好的「基本功」**，**开箱即用**。

- 典型能力：读写您授权范围内的 **本地文件**、执行安全的 **基础网页获取**、部分 **系统级原子操作** 等（以实际内置清单为准）。  
- **您一般不需要** 在 Store 里单独「订阅」Tools 才能用这些底座能力；只要 Omni 与 L3 正常运行，就会按权限自动出现在助手的工具箱里。

> **提示 (Tip)**：若文档其它地方提到「Native / 内置工具」，多半指的就是这类 **宿主自带** 能力，与下面要 **主动订阅** 的 Skills、MCPs 不同。

### 4.2 🧠 Skills（专属技能）

相当于给 Omni 配了一套 **高级 SOP 或专业人设**：比如「资深文案排版」「专属代码审查清单」「某业务领域的固定流程」——写在声明式 **SKILL.md** 里，由助手按套路执行。

- **需要您在 Store 里主动「订阅」** 后，对应能力才会进入您工作区 / 边缘节点的可用列表。  
- 订阅前可在商店里阅读简介，确认是否符合团队场景；未订阅时，助手不会凭空拥有该技能。

### 4.3 🔌 MCPs（深度插件 / 模型上下文协议）

可以把 MCP 理解成 **连接外部世界的长桥**：接 **本地数据库**、**Notion**、**飞书 (Lark)**、其它 HTTP 服务或复杂软件，让 Omni 在对话里 **真实调用** 这些系统，而不只是「口头描述」。

- **同样需要您在 Store 里主动「订阅」** 后才会启用。  
- 部分 MCP 连接外部服务时，可能要您在 **配置里填写 API Key、Webhook、租户信息** 等；按插件说明与团队安全规范操作即可。

> **注意 (Note)**：您在 Store 中 **订阅的 Skills 和 MCPs** 会由云端清单经 **L2** 同步到已接驳的 **桌面端 L3 节点**，一般 **无需** 再单独下载 Windows 安装包或手动拷贝插件文件；同步时间与网络、审批状态有关，若长时间未生效可联系管理员排查。

## 9. 配对说明（管理员与普通用户分工）

### 9.1 L1 ↔ L2（仅管理员需要操作）

**目的**：让 **管理网关** 信任您在 **神经集市** 的团队身份，以便同步商店清单、技能订阅等。

1. 浏览器打开：**http://47.86.39.173:18888/gateway/**  
2. **推荐**：在登录框 **用户名** 填 L1 注册 **邮箱**，**密码** 填 **L1 同一密码**（L2 不会保存您的密码，由服务端向 L1 校验）。  
3. 若 L1 仅支持第三方登录、未设密码：可使用 **「使用 Nexus 账号登录（推荐）」** 跳转到 L1 授权后再返回（需部署正确）。  
4. 部分环境提供运维账号 **`admin` / `admin123`**（若未修改），仅作维护兜底；生产环境请按团队要求修改并绑定 L1。  
5. 曾经配对成功的设备，可尝试 **「快速登录」**（需 L1 可访问且账号在 L1 侧具备网关权限）。

**权限**：与 L1 联邦登录相关的操作，通常只有工作区 **负责人 (owner) / 管理员 (admin)** 能完成；普通成员可能 **无法登录 L2**，这是正常现象。

> 📸 **[截图占位：L2 网关登录成功后的管理首页缩略图]**

### 9.2 L2 ↔ L3（神经接驳：用户发起 + 管理员审批）

**目的**：让您的 **电脑** 接入团队，安全接收 **加密下发的 API Key**、同步已订阅技能等。

1. 打开 **桌面端**，在设置中找到 **神经接驳** 或 **连接 L2 网关**。  
2. **网关地址**填：**`http://47.86.39.173:18888`**（是否包含 `/gateway/` 以客户端提示为准）。  
3. 提交后，设备会进入 **待审批**。  
4. **管理员** 登录 L2：**http://47.86.39.173:18888/gateway/** ，在 **节点审批** 中找到对应设备，选择 **子账号** 并 **同意接入**。  
5. 回到桌面端等待 **审批通过** 与配置生效（以界面提示为准）。

> **注意 (Note)**：不存在 **「L1 与电脑直接配对」** 的流程；**审批电脑接入只在 L2 管理网关完成。**

### 9.3 无图形界面的服务器（可选）

若设备没有显示器、只有 SSH，可由运维用 **命令行配对** 等方式辅助 L1↔L2（普通用户可忽略）。

## 10. 安装后如何使用（日常使用）

1. 启动桌面端，确认 **已与 L2 接驳成功**（或按团队说明使用仅本地 Key 的模式）。  
2. 在 **Omni** 对话区输入任务；智能体会按已订阅的 **技能** 与 **插件能力** 执行。  
3. 在 L1 **神经集市** 新订阅的技能或插件，一般会经 L2 同步到您的电脑；若长时间不可用，请检查网络、L2 与权限。

## 11. 如何关闭程序（与「仅隐藏窗口」的区别）

适用于 **Jachin 桌面端（Windows）**。

1. **点主窗口右上角关闭**  
   多数情况下 **不会退出软件**，而是 **隐藏窗口**；程序仍在 **系统托盘**（任务栏右下角）保留图标。  
2. **彻底退出**  
   在托盘图标上 **右键** → 选择 **「退出 Jachin」**。关机、卸载前建议先执行此步。  
3. **再次打开**  
   若程序已在后台运行，再次从开始菜单启动时通常会 **聚焦已有窗口**（单实例），而不会无限多开。

## 12. 快捷键与托盘（唤出 Omni / 控制台）

若与您安装的版本不一致，以软件内说明为准。

### 12.1 系统托盘

| 操作 | 作用 |
|------|------|
| **左键单击** 托盘图标 | 打开或切换 **Omni**（对话界面） |
| **右键单击** 托盘图标 | **「打开控制台」**、**「退出 Jachin」** |

### 12.2 全局快捷键（用于 Omni）

程序会依次尝试注册以下组合，**以第一个注册成功的为准**（常见为第一种）：

1. **`Alt` + `Shift` + `空格`**  
2. **`Ctrl` + `Shift` + `空格`**（上一项失败时可能使用）  
3. **`Alt` + `空格`**（再失败时可能尝试；易与其它软件冲突）

> **注意 (Note)**：在 Windows 上 **`Alt` + `空格`** 可能被 **PowerToys「运行」** 等软件占用。若全局快捷键无效，请到 PowerToys 或其它热键工具中 **关闭冲突项**，或 **改用托盘左键** 打开 Omni。

### 12.3 控制台窗口在前台时（焦点在主界面内）

| 快捷键 | 作用 |
|--------|------|
| **`Ctrl` + `Shift` + `E`** | **鹰眼监控**：显示/隐藏 **控制台** 主窗口 |
| **`Ctrl` + `Shift` + `C`** | **打开聊天窗口（Omni）** |

## 14. 常见问题与故障排除（FAQ & Troubleshooting）

### 14.1 入门与地址

**Q：我第一步到底该点哪个网站？**  
A：日常用户先收藏 **L1**：**http://47.86.39.173:3000/** ，完成注册与下载。需要 **审批别人电脑** 的管理员再使用 **L2**：**http://47.86.39.173:18888/gateway/** 。

**Q：L1 或 L2 网页打不开、一直转圈？**  
A：检查本机网络是否正常；公司网络是否拦截；是否需配置 **系统代理 / VPN**（按公司规定）。仍不行请联系 **运维** 确认服务是否在线、地址是否变更。

### 14.2 账号与权限

**Q：登录 L2 提示 403 或无权限？**  
A：您可能不是工作区的 **owner/admin**，或 L1 账号未与网关完成绑定。请联系 **组织管理员** 为您开通或代为审批。

**Q：普通成员也要登录 L2 吗？**  
A：**一般不需要**。只有需要 **审批设备**、管理子账号的人需要登录 L2。

### 14.3 神经接驳与节点状态

**Q：桌面端一直显示「待审批」？**  
A：请管理员登录 L2 **节点审批** 完成分配；并确认桌面端填写的 **L2 地址** 正确、当前网络能访问该地址。

**Q：感觉「节点离线」或连不上 L2？**  
A：先确认 **浏览器能否打开** 同一 L2 地址；再检查桌面端 **网关 URL** 是否填错（多余空格、少了 `http://` 等）。公司网络若需代理，按 IT 要求配置后再试。

**Q：能否不经过 L2 使用？**  
A：部分版本支持 **仅本地 API Key** 模式（跳过 L2），但可能 **无法使用** 依赖云端同步的订阅能力；以客户端选项与团队说明为准。

### 14.4 窗口、托盘与快捷键

**Q：点了关闭，为什么程序还在跑？**  
A：关闭主窗口通常是 **隐藏**，程序仍在 **托盘**。彻底退出请 **右键托盘 →「退出 Jachin」**。

**Q：按了 `Alt` + `Shift` + `空格` 没反应？**  
A：可能全局快捷键未注册成功或被其它软件占用。请尝试 **托盘左键** 打开 Omni；检查 **PowerToys** 等热键冲突；确认程序未在已退出的状态。

**Q：无法唤出控制台主窗口？**  
A：使用托盘 **右键 →「打开控制台」**；或在控制台已打开时按 **`Ctrl` + `Shift` + `E`** 切换鹰眼显示状态。

## 15. 常见使用场景与示例 (Use Cases)

在 **Omni** 里，您用自然语言说出需求即可。下面按场景分类列出 **口语化示例**、**背后大致会做什么**，以及必要的 **边界说明**。实际可调用的工具与技能以您团队 **已订阅** 的内容及权限为准。

建议：**先完成上文中的地址、下载、安装、配对与快捷键（约第 5～13 章）**，再按下列示例尝试，成功率更高。

### 15.1 📁 办公与本地文件管理

适合：写材料、整理表格、处理放在本机的 PDF / Word / 笔记等。

#### 读取并整理本地文档

> 帮我把桌面上的《会议纪要.pdf》读一遍，用三条 bullet 总结决议事项，并标出谁负责跟进。

**动作解析**：Omni 通过 **本地文件读取 / 工作区** 相关能力访问您授权路径下的文件，提取正文后归纳要点（具体工具名随部署与权限变化）。

> 这个文件夹里一堆报销扫描件，帮我按日期排个序，列个表告诉我每张大概是几月几号的。

**动作解析**：遍历目录、读取各文件元数据或内容摘要，输出 **整理清单**（可能以对话表格或 Markdown 呈现）。

#### 办公自动化：自动写 Word、Excel

> 帮我写一份「项目周报」Word，章节要有：本周进展、风险、下周计划，语气正式一点，保存到我指定的目录。

**动作解析**：通过 **文档生成类工具**（如 `util:generate_office_doc` 等，以实际订阅为准）在允许的目录下生成 **`.docx` / `.xlsx`**，并在回复中给出保存路径。

> 做一个简单的 Excel：第一列姓名、第二列 Q1 销售额，随便造几行示例数据，我好拿去演示格式。

**动作解析**：生成表格文件并写入示例数据，便于您本地再改真实数字。

> **提示 (Tip)**：生成文件通常落在 **`~/.jachin/workspace/`** 或客户端允许的路径；若保存失败，请检查路径是否在白名单内或询问管理员。

### 15.2 🌐 网页信息处理

适合：快速抓文章要点、对照多篇文章、跟进公开网页上的信息（**非登录墙、非强反爬站点**成功率更高）。

#### 联网读取网页内容

> 把这个新闻链接打开帮我总结一下核心观点，顺便说有没有引用数据来源：https://example.com/article

**动作解析**：通过 **网页抓取 / 阅读类 MCP 或工具** 请求 URL，将正文送入模型 **摘要与归纳**。

> 帮我盯一下这个文档页面有没有更新，把和上周相比多出来的段落列出来。

**动作解析**：拉取当前页面文本（或缓存对比），做 **差异说明**（视工具能力可能为单次快照摘要）。

> 💡 **提示**：部分带有 **强力防爬虫、登录墙、频繁人机验证** 的网站，可能无法稳定抓取正文。此时可改用 **手动复制粘贴** 关键段落到 Omni，或换用公开可访问的镜像链接。

### 15.3 ☕ 日常生活与效率助手

适合：出门前看一眼天、排行程、随手记一笔、让助手到时喊您一声。

#### 生活助手：查天气、出行规划、日常记账

> 我明天从北京去上海出差，帮我看看两地天气差多少，要不要带外套。

**动作解析**：结合 **联网检索或天气类工具** 返回预报摘要，并给出 **穿衣/出行建议**（非专业气象预报，仅供参考）。

> 周末想带娃去郊区玩一天，从我家出发开车别超过两小时，给两个轻松一点的方案。

**动作解析**：基于常识与公开信息做 **路线级规划草案**；精确路况以导航软件为准。

> 这个月咖啡和外卖大概花了多少？我把几笔金额发你：35、42、28……

**动作解析**：在对话中做 **简单加总与分类**；若需长期账本，建议固定格式或表格文件由 Omni 协助维护。

#### 效率管理：设置定时提醒

> 今天下午 4 点提醒我提交周报，标题写「别忘交周报」。

**动作解析**：通过客户端 **提醒 / 日程** 相关能力（若已启用）写入 **本地定时提醒**；也可能以对话形式给出 **ICS 文案** 或清单，取决于版本与权限。

> 每天晚上 10 点提醒我关机前备份桌面上的「项目」文件夹——先告诉我你打算怎么提醒。

**动作解析**：确认 **重复规则** 与 **提醒渠道**（系统通知 / 应用内），再创建或给出可手动设置的步骤。

> **注意 (Note)**：提醒功能依赖 **系统通知权限** 与客户端实现；若未弹出，请在 Windows **通知与专注** 设置中允许 Jachin 通知。

### 15.4 使用小结

| 您想做的事 | 在 Omni 里可以怎么说 |
|------------|----------------------|
| 处理本地文件 | 直接说清 **文件路径或文件夹**，以及要 **总结 / 转换 / 生成** 成什么 |
| 看网页在讲什么 | 粘贴 **URL**，说明要 **摘要、对比、提取表格** 等 |
| 写 Office | 说明 **文档类型、大纲、语气**，以及 **希望保存的大致位置** |
| 生活与效率 | 用 **时间、地点、预算** 等口语约束，越具体越好 |

若某条指令提示「无权调用工具」，请联系管理员确认 **技能 / MCP 是否已订阅** 以及 **本机是否已完成神经接驳**。

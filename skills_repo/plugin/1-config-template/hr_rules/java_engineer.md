# Java 工程师筛选条件

> 部署时复制到 ~/.jachin/workspace/hr_rules/java_engineer.md
> HR 可直接编辑此文件调整筛选标准，无需改代码

## 硬性条件

1. **学历**：必须是统招全日制本科，学历不符直接淘汰。
2. **经验**：Java 开发经验不得低于 3 年，必须有 SpringCloud 微服务经验。
3. **稳定性**：一年内跳槽超过 2 次的直接淘汰，稳定性极差。

## 加分项

- 有高并发、分布式系统实战经验
- 熟悉 Redis、Kafka、Elasticsearch
- 有技术博客或开源贡献

## 淘汰信号

- 简历夸大、项目经历含糊
- 自我评价与经历明显矛盾
- 频繁换行业/岗位方向

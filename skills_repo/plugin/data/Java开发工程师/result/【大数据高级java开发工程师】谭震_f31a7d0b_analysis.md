1. 评价中台核心设计： 负责评价中心从 C 端发布、机审分流到 B 端管控的全链路开发。利用 RocketMQ 事务消息 解决了评价发

机制，并利用 MQ 削峰填谷特性平滑处理高并发下的机审请求。

制，成功防御了恶意灌水及爬虫攻击，保障了中台服务对数字展厅、售后系统等外部调用的安全性。

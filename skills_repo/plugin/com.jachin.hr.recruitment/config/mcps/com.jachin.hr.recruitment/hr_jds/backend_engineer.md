# 后端工程师 - 岗位要求 (JD)

## 岗位名称
后端工程师 /后端架构师

## 核心职责
- 负责协同架构下的后端服务设计与开发
- 参与边缘计算平台、数据同步与离线容错机制的设计与实现
- 支撑百万级设备接入的高可用分布式系统

## 技术栈要求
- **必备**：Rust 或 Go 至少一门精通，具备生产级项目经验
- **必备**：分布式系统、高可用设计、Kubernetes 等云原生技术
- **加分**：边缘计算、零拷贝/高性能网络、多级权限与审计日志

## 经验要求
- 3 年以上后端开发经验，有架构设计或技术主导经历
- 有云边协同、IoT、或政企内网数据湖等场景经验优先

## 软性素质
- 良好的团队协作与沟通能力
- 自驱力强，能独立攻坚技术难点
- 具备复盘迭代与抗压能力

## 学历与稳定性
- 本科及以上学历（计算机相关专业优先）
- 跳槽频率合理，有 2 年以上单司任职经历优先
